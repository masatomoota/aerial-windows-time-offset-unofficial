# Aerial 設定インポート/エクスポート機能マニュアル

## 対象
- `Aerial_masatomo` 1.2.1 系
- Advanced Settings に追加された `Import / Export Settings` 機能

## この機能でできること
- 同じ PC に入っている別の Aerial から、現在の Aerial へ設定を取り込む
- 現在の Aerial の設定を、同じ PC に入っている別の Aerial へ書き出す

## どこにあるか
1. Aerial の設定画面を開きます。
2. `Settings` タブを開きます。
3. 左側の `Advanced` を開きます。
4. `Import / Export Settings` セクションを使います。

## 使い方

### 1. 候補一覧を更新する
1. `Refresh List` を押します。
2. 一覧に、同じ PC の `AppData` 内で見つかった他の Aerial が表示されます。
3. 目的の Aerial を選択します。

### 2. 他の Aerial から取り込む
1. 一覧から取り込み元を選択します。
2. `Import Selected Settings` を押します。
3. 確認ダイアログで `OK` を押します。
4. 取り込み完了メッセージが表示されたら完了です。

取り込み後の挙動:
- この Aerial の設定画面はその場で更新されます。
- 表示設定、再生設定、時刻設定、マルチスクリーン設定、テキスト設定などが反映されます。

### 3. 現在の設定を他の Aerial に書き出す
1. 一覧から書き出し先を選択します。
2. `Export Current Settings` を押します。
3. 確認ダイアログで `OK` を押します。
4. 完了メッセージが表示されたら終了です。

書き出し後の挙動:
- 書き出し先の `config.json` が更新されます。
- 書き出し先の Aerial が起動中なら、再起動して反映してください。

## コピーされる主な設定
- 動画選択状態
- 再生速度、トランジション、フィルター
- 時刻表示オフセット
- 日の出/日の入り関連設定
- マルチスクリーン設定
- テキスト表示設定
- グローバルショートカット設定
- カスタム動画設定

## コピーされない設定
各インストール固有の情報は意図的にコピーしません。

例:
- キャッシュ保存先
- ダウンロード済み動画一覧
- キャッシュサイズ
- 画面数
- バージョン情報
- 更新通知状態

## 一覧に他の Aerial が出ないとき
- 対象の Aerial を一度起動して、`config.json` が作成されていることを確認してください。
- 同じ Windows ユーザーの `AppData` 配下に存在している必要があります。
- この機能は、名前に `Aerial` を含む設定ディレクトリを検出対象にしています。

## 推奨運用
- まずメインで使う Aerial を整える
- 他の Aerial には `Export Current Settings` で配る
- 他の Aerial 側で個別調整した場合は、必要に応じて逆方向に `Import Selected Settings` を使う
