# Aerial for Windows Time Offset (Unofficial)

英語版ドキュメントは [README.md](./README.md) にあります。

このリポジトリは、Windows向けスクリーンセーバー [OrangeJedi/Aerial](https://github.com/OrangeJedi/Aerial) の非公式フォークです。

このフォークには、時刻表示に任意のオフセットを適用できる機能など、個人利用向けのカスタマイズが含まれています。

## フォークに関する注意

- このリポジトリは公式版ではありません。

- 公式サポートや上流機能については元プロジェクトを参照してください。

帰属表示やライセンスに関する注意は [NOTICE.ja.md](./NOTICE.ja.md) を参照してください。  
公開時の手順は [FORK_PUBLISHING.ja.md](./FORK_PUBLISHING.ja.md) を参照してください。

## インストール
このリポジトリの Releases ページから最新リリースをダウンロードし、インストーラーを実行してください。

必要に応じて、OSの画面/スリープ設定を調整し、他のスクリーンセーバーを無効化してください。

## 機能
- WindowsでApple TV風の空撮スクリーンセーバーを再生
- 時刻/日付、場所、日の出/日の入りなどの情報をオーバーレイ表示
- ローカル動画再生やキャッシュによるオフライン再生
- フォーク独自機能: 時刻表示オフセットの設定
