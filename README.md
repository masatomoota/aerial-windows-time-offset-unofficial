# Aerial for Windows Time Offset (Unofficial)

Japanese documentation is available at [README.ja.md](./README.ja.md).

This repository is an unofficial fork of [OrangeJedi/Aerial](https://github.com/OrangeJedi/Aerial), a Windows screen saver that mimics Apple's Apple TV screen saver.

This fork adds personal customizations, including support for applying a custom time display offset.

## Fork Notice
- Upstream project: [OrangeJedi/Aerial](https://github.com/OrangeJedi/Aerial)

- Compatibility, behavior, and release cadence may differ from upstream.
- For upstream features and official support, use the original project.

See [NOTICE.md](./NOTICE.md) for attribution and license notes for this fork.
See [FORK_PUBLISHING.md](./FORK_PUBLISHING.md) for publishing checklist and naming guidance.

## Installing
Download the latest fork release from this repository's Releases page and run the installer.

Be sure to configure system screen/sleep settings and disable other screensavers as needed.

## Features
- Apple TV-style aerial video screensaver on Windows.
- Overlay information such as time/date, location, and sunrise/sunset.
- Optional local video playback and cached offline playback.
- Fork customization: configurable time display offset.
